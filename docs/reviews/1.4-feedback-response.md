# Response to the wondev 1.4.0 Windows evaluation

The original evaluation's three attachments were not present in this checkout. This
records implementation acceptance criteria based on the submitted findings; it does not
claim to reproduce the author's complete sixteen-observation fixture.

| Finding | Acceptance criteria | Regression evidence |
| --- | --- | --- |
| False CRLF conflicts | A clean clone with `core.autocrlf=true` passes check/build without a dirty manifest; actual prose and binary edits still fail | `test/upgrade-diagnostics.test.ts` |
| Bundled skills after adopt | Selective install works without starter provenance; future upgrades remain scoped; user collisions are preserved | `test/upgrade-diagnostics.test.ts` |
| Ignored outputs | Optional diagnostics identify ignored/untracked/missing/index-tracked output and the responsible ignore rule; plain check remains offline and unchanged | `test/upgrade-diagnostics.test.ts` |
| Existing vault migration | Preview titles, conflicts and links; explicit per-note choices; stale hashes and invalid links block apply; original bytes/config backed up; one active memory source | `test/vault-reconcile.test.ts` |
| Mixed workspace mapping | Validated service roots, unsupported-language inventory, per-service coverage and unresolved import counts; no fabricated cross-language edges | `test/map-coverage.test.ts` |
| Curated plugin controls | Offline catalog, explicit exact pins, separate export enablement, verified registry metadata, opt-in update checks and no host mutation | `test/plugin-catalog.test.ts` |

The documentation distinguishes native skill output copies from duplicate authored memory,
and distinguishes the Understand Anything bridge from its full runtime. Graphify, native
mapping, graph exploration and curated memory have complementary roles rather than being
treated as interchangeable features.

Run `npm run verify` for all behavior tests, `npm run test:package` for the installed
tarball, and `npm run test:upgrade:previous` for an upgrade from published 1.4.0. The CI
matrix repeats verification and package/upgrade checks on Windows, macOS and Linux.
